## 🌍 **Travel Destinations App**

Malá webová stránka vo Vue 3 venovaná európskym krajinám a ich charakteristikám.
Používatelia si môžu prezerať krajiny, otvárať podrobné stránky a objavovať zaujímavé fakty o nich.

---

## 🛠 **Použité technológie**

- `Vue 3`
- `Vue Router`
- `JavaScript`
- `CSS`
- `JSON` ako zdroj údajov
- `TypeScript` pre kontrolu typu údajov zo súboru
- `Pinia` používa sa ako centralizované úložisko údajov
- `LocalStore` používa sa na ukladanie údajov v prehliadači
